# 字幕样式预览设计

## 目标

在快速创作页的“字幕样式”模块中，提供与现有配置实时联动的静态预览和可重复播放的动态预览。用户无需创建视频即可判断字幕在不同内容背景、不同画幅上的可读性与位置。

此功能只消费现有 `SubtitleStyle` 配置，不改变视频创建接口、预设保存格式或服务端字幕渲染参数。

## 已确认的产品决定

- 采用混合预览：前端即时静态预览，加一个按需播放的 2.5 秒动态效果。
- 使用内置场景素材，不依赖用户上传或已生成的视频帧。
- 预览放在展开后的字幕样式面板顶部。
- 支持四类场景：明亮、暗色、人像、复杂背景。
- 支持 16:9 与 9:16 两种画幅。
- 预览需要反映现有全部字幕参数：预设、字体、字号、主/强调/描边/底色、描边宽度、阴影、底部边距、每行字数、最大行数、分段方式及动画。

## 方案选择

### 方案 A：纯 CSS 模拟

优点是零网络延迟和实现快速；缺点是字体加载、断行和描边效果可能与最终渲染不一致。

### 方案 B：每次修改均由后端渲染

优点是最接近成片；缺点是调整颜色或字号时需频繁请求，编辑体验差且消耗渲染资源。

### 方案 C：混合方案（采用）

静态画面由浏览器即时绘制；点击“播放效果”后，在浏览器中演示现有分段和动画语义。预览用与表单相同的样式映射、缩放和断行规则。服务端继续以既有逻辑处理实际成片，预览不创建额外任务。

## 界面与交互

字幕启用后，在样式面板标题和预设选择器之前放置预览卡片。

预览卡片包含：

- 16:9 或 9:16 的背景画面，并在安全区域内叠加示例字幕“让每一帧，都更有表达力”。
- 场景切换控件：明亮、暗色、人像、复杂。
- 画幅切换控件：16:9、9:16。
- “播放效果”按钮。播放时显示当前 `segmentMode` 的分段顺序，以及 `fade` 或 `none` 的过渡效果；播放结束后可立即重播。
- 回退字体提示：选择仅在服务端可访问的本地字体路径且浏览器无法加载时，画面使用浏览器回退字体，并显示“预览使用回退字体”。
- 提示文案：“实时预览为近似效果，最终以渲染成片为准。”

用户改动任一字幕字段后，预览在 100ms 内更新。切换预设时，表单和预览同步更新。字幕关闭时，预览卡与样式表单一起隐藏。

## 组件、数据与状态

新增 `SubtitleStylePreview`，由 `QuickCreate` 传入当前的 `SubtitleStyle`。`QuickCreate` 仍是样式配置的唯一数据源。

建议 props：

```ts
type SubtitleStylePreviewProps = {
  style: SubtitleStyle;
  aspectRatio: "landscape" | "portrait";
  onAspectRatioChange: (ratio: "landscape" | "portrait") => void;
};
```

组件内部维护纯展示状态：当前场景、是否播放、当前字幕切片和播放计时。它不修改字幕样式、不保存预设、不调用视频创建接口。

提取三个无副作用的工具函数：

- `wrapPreviewText`：基于 `maxCharsPerLine` 和 `maxLines` 断行、截断示例文案。
- `scaleStyleForPreview`：根据画幅、预览尺寸和安全边距缩放字号、描边、阴影和底距。
- `segmentPreviewText`：按 `phrase`、`sentence`、`line` 返回动态预览的切片。

## 与最终成片的一致性

- 使用现有 `SubtitleStyle` 字段和同一份预设数据，不引入单独的预览样式模型。
- 预览按目标画幅比例缩放，但不伪造服务端尚未支持的动画效果；仅实现 `fade` 和 `none`。
- 服务端路径字体在浏览器中不可直接加载时不得静默伪装为已生效；必须显示回退提示，同时原字体路径继续随实际创建请求提交。
- 颜色仅接受已有的 `#RRGGBB` 值；无效值回退预设默认值。
- 对字号、边距和描边做二次范围钳制，避免字幕在预览中溢出画布。

## 非目标

- 不上传或生成用户专属预览背景。
- 不添加新的字幕动画、逐字高亮或卡拉 OK 效果。
- 不在预览期间调用后端视频或图片渲染。
- 不修改现有创建请求的 `subtitle_style` 结构。

## 验收标准

1. 开启字幕后显示预览卡，关闭字幕后隐藏。
2. 改变任何现有字幕参数，静态预览在 100ms 内更新。
3. 四种背景与两种画幅均可切换，字幕始终保留安全边距。
4. 动态播放正确体现 `fade` / `none` 和三种分段模式，且可重复播放。
5. 四个预设切换后，预览与表单参数一致。
6. 浏览器不能加载的自定义字体会显示回退提示，不影响实际提交的字体路径。
7. 创建接口请求、预设的保存/读取及最终视频生成行为不变。

## 验证策略

- 为断行、缩放、分段函数写单元测试，覆盖中文、英文、标点、超长文本和边界数字。
- 为预览组件写交互测试，覆盖场景/画幅切换、样式同步、动画重播和字体回退提示。
- 手工检查桌面与窄屏布局，并用现有四个字幕预设比对生成视频的视觉结果。
