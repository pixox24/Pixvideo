**版本**：1.0  
**对应组件**：  
- 生成台 → `frontend/src/components/QuickCreate.tsx`（+ `quickCreate/wizard.ts`）

### 1.2 侧栏信息优先级

| 区域 | 内容 | 默认 |
|------|------|------|
| 顶 | Logo + 产品名 | 常显 |
| 中 | 导航 4 项（分组标题可保留） | 常显 |
| 底 | **一行**服务就绪摘要 `3/6`；点击展开详情 | 默认折叠详情 |

**移出侧栏默认视野**（可进设置或展开）：RunningHub 长状态文案、逐服务完整 detail 列表（展开后仍可访问）。

### 1.3 建议 DOM（App.tsx）

```html
<div class="app-shell flex h-screen">
  <aside class="app-nav">...</aside>
  <div class="app-main flex min-w-0 flex-1 flex-col">
    <!-- 可选: 全局 slim banner（配置引导） -->
    <main class="min-h-0 flex-1 overflow-hidden or overflow-y-auto">
      <!-- tab content -->
    </main>
  </div>
  <!-- ConsolePanel -->
</div>
```

- 生成台：`main` **可纵向滚动**。  
- 精修台：`main` **`overflow-hidden` + 子树全高**，禁止整页滚走时间线。

## 2. 生成台（QuickCreate）线框

### 2.1 设计目标

- 用户始终知道步骤：内容 → 风格 → 声音 → 确认。  
- **每步一个主卡片**；高级参数折叠。  
- 底部 sticky：**主 CTA**（进入工作台 / 直接生成）。  
- 宽屏可选右侧 **分镜摘要轨**（只读列表，增强结果感）。

### 2.2 顶区：步骤条（全步骤常显）

```
┌─────────────────────────────────────────────────────────────┐
│  开始创作                              预设 ▾   专家模式    │
│                                                             │
│  (1) 内容 ──── (2) 风格 ──── (3) 声音 ──── (4) 确认         │
│   ●完成         ○当前         ○             ○               │
└─────────────────────────────────────────────────────────────┘
```

**映射现有**：

| 步骤 | 现 wizard / stage id（参考） | 现内容迁入 |
|------|------------------------------|------------|
| 1 内容 | `content` / `stage-content` | 主题、文案草稿、分镜数量、切分规则、字数、关键词 |
| 2 风格 | 原 production 中画面部分 | 画幅、workflow、prompt 前缀、运动/字幕开关粗设 |
| 3 声音 | 原 production 中 TTS/BGM | TTS 模式、音色、语速、MiMo/MiniMax、BGM |
| 4 确认 | `review` / `stage-review` | 分镜预览列表、复用素材、确认勾选、提交 |

字幕细调（样式面板）可放在步骤 2「高级 · 字幕样式」或确认步折叠。

### 2.3 步骤 1 · 内容（主卡片）

```
┌─ main column max-w-3xl ──────────────┐  ┌─ summary rail (xl+) ──┐
│                                      │  │ 分镜摘要               │
│  项目标题                            │  │ #1 ……                 │
│  [________________________]          │  │ #2 ……                 │
│                                      │  │ …                     │
│  创作主题                            │  │ 共 N 镜 · 语义建议     │
│  [ 大文本域 / 大输入 ]               │  │                        │
│                                      │  └────────────────────────┘
│  [ AI 生成文案草稿 ]                 │
│                                      │
│  确认文案                            │
│  ┌ 整篇 | 分镜列表 ─┐                │
│  │ 大文本域          │                │
│  └───────────────────┘                │
│                                      │
│  ┌ 分镜数量 ] [ 字数 ] [ 切分规则 ]  │  ← 三列紧凑工具条，非第三套大卡片
│  │ 语义建议提示…                    │
│  └──────────────────────────────────│
│                                      │
│  ▸ 高级：关键词高亮                   │
└──────────────────────────────────────┘
```

**实现要点**：

- 主题输入：`min-h-[88px]` 或更大，圆角 `radius-lg`。  
- 分镜数量：数字输入（已落地），保留语义建议文案。  
- 关键词区：默认折叠 `details` / 手风琴。

### 2.4 步骤 2 · 风格

```
┌─ 主卡片 ─────────────────────────────┐
│  画幅                                 │
│  [ 9:16 ] [ 16:9 ] [ 1:1 ] [ 自定义 ] │  ← 大按钮组，非仅 select
│                                      │
│  画面工作流                           │
│  [ Select 工作流 ]                    │
│                                      │
│  风格前缀                             │
│  [ textarea 3 行 ]                    │
│                                      │
│  [x] 运动  [x] 字幕                   │
│                                      │
│  ▸ 高级：字幕样式面板 / 字体           │
└──────────────────────────────────────┘
```

### 2.5 步骤 3 · 声音

```
┌─ 主卡片 ─────────────────────────────┐
│  配音                                 │
│  [ Edge ] [ MiniMax ] [ MiMo ] …      │  ← 分段控件
│  音色 [ select ]  语速 [ slider/num ] │

│                                      │
│  ▸ 高级：连续合成 / 情绪 / voice design│
└──────────────────────────────────────┘
```

### 2.6 步骤 4 · 确认

```
┌─ 主卡片 ─────────────────────────────┐
│  将生成 N 个分镜 · 预计口播 Xs         │
│                                      │
│  ┌ 分镜条 1 旁白摘要 ─────────────┐  │
│  ├ 分镜条 2 ──────────────────────┤  │
│  └ … ─────────────────────────────┘  │
│                                      │
│  [ ] 复用历史素材（若有）             │
│  [ ] 我已确认文案与设置               │
│                                      │
│  配置摘要：MiMo · 9:16 · BGM xx       │
└──────────────────────────────────────┘

┌─ sticky footer ──────────────────────┐
│  上一步     [ 生成并进入精修 ] 主CTA  │
│             [ 直接渲染成片 ] 次要     │
└──────────────────────────────────────┘
```

### 2.7 专家模式

- 现有 `expertMode`：可继续 **单页长卷** 展示全部步骤卡片，但仍用同一套卡片样式与 sticky CTA。  
- 新手模式：严格单步；步骤条可点击已完成步。

### 2.8 建议组件树（不改业务 state 名）

```
QuickCreate
├── CreateHeader (标题、预设、专家模式)
├── Stepper (WIZARD_STEPS 映射四步)
├── StepPanel

│   ├── VoiceStep
```

可先在 `QuickCreate.tsx` 内分区注释 + class，再物理拆文件（见实施计划 PR）。

### 2.9 功能保全清单（生成台）

以下必须仍可达（可折叠）：

- AI / 手动 / 批量 mode  
- 文案草稿生成、分镜脚本生成  
- 全部 TTS 模式与试听  
- BGM 试听  
- 字幕样式全量字段  
- 预设 CRUD  
- 复用历史素材  
- 进入工作台 / 直接生成

## 3. 精修台（ProjectWorkbench）线框

### 3.1 设计目标

- **预览是舞台**，时间线是骨架，分镜列表是目录，检查器是上下文。  
- 顶栏单行；BGM/全局设置不常驻多横条。  
- 圆润：舞台 `radius-xl`，轨道圆角，少硬线。

### 3.2 整体（桌面）

```
┌─ workbench root flex-col h-full ─────────────────────────────────────┐
│ TOPBAR (h-14, 单行)                                                   │
│  [标题]  N镜 · 状态胶囊     [生成进度]    [项目设置] [导出成片●] [刷新]│
├───────────────────────────────────────────────────────────────────────┤
│ 可选：GenerationRunPanel 一条 slim 进度（仅在有 run 时）               │
├────────────┬─────────────────────────────┬────────────────────────────┤
│ SCENE RAIL │ STAGE                       │ INSPECTOR                  │
│ w-56~60    │ flex-1                      │ w-72~80                    │
│            │                             │                            │
│ 分镜列表   │  播放控件（浮在舞台上/下）   │  当前分镜旁白/提示词        │
│ 缩略图+文  │  ┌─────────────────────┐   │  版本/候选                 │
│ 案两行     │  │                     │   │  重生成 / 上传             │
│            │  │    预览图/黑场       │   │                            │
│            │  │    radius-xl         │   │  Tab: 画面 | 音频 | 字幕   │
│            │  │    shadow-stage      │   │  （减少一屏字段）          │
│            │  └─────────────────────┘   │                            │
│            │  时间 00:12 / 00:48         │                            │
├────────────┴─────────────────────────────┴────────────────────────────┤
│ TIMELINE (h-36~44)  圆角容器 surface-2                                │
│  工具：缩放 撤销 重做 |  轨道 + playhead                               │
├───────────────────────────────────────────────────────────────────────┤
│ 可选折叠：任务队列 GenerationQueue（默认折叠为「N 个任务」）           │
└───────────────────────────────────────────────────────────────────────┘
```

### 3.3 顶栏合并规则（相对现状）

| 现横条 | 改造后位置 |
|--------|------------|
| 标题 + 导出 + 刷新 | TOPBAR 主行 |
| BGM + 音量 + 字幕勾选 + 保存设置 | **项目设置** Drawer / Popover |
| 快捷键 tip | 首次显示，可「知道了」；或 `?` 菜单 |
| 批量选中工具条 | 仅多选时出现 **覆盖条**（overlay bar） |
| GenerationRunPanel | 单行 slim，保留操作按钮 |

### 3.4 分镜列表（SceneList）

```
┌ 分镜 ──────────────┐
│ #1  ▓▓ 旁白摘要…   │  ← 选中：左侧 brand 条 + surface-3
│ #2  ▓▓ …           │
│ #3  生成中…        │  ← 状态点：ready / missing / running
└────────────────────┘
```

- 行高舒适 56–64px；圆角行 `rounded-md`。  
- 复选框默认弱化，hover/多选模式再强调。

### 3.5 预览舞台（Stage）

```
┌──────────────────────────────────────┐
│           surface-0 内衬              │
│   ┌────────────────────────────┐     │
│   │                            │     │
│   │     img object-contain     │     │
│   │     或空状态插画            │     │
│   │                            │     │
│   └────────────────────────────┘     │
│      ‹  ▶  ›     00:12 / 00:48       │
└──────────────────────────────────────┘
```

- 播放按钮：**圆形**主色或白半透明，直径 40–48px。  
- 隐藏的 `<audio>` 保持逻辑不变。

### 3.6 检查器（SceneInspector）

建议视觉 Tab（纯 UI 分组，state 可仍一份）：

1. **画面** — 提示词、重生成图、版本  
2. **旁白** — 文本、重生成 TTS  
3. **更多** — 上传等  

字段不删，只分栏减少压迫感。

### 3.7 时间线（WorkbenchTimeline）

- 外层：`rounded-xl bg-surface-2 p-2`  
- 轨道块：`rounded-lg`，选中 `ring-2 ring-brand-500/40`  
- 刻度字：caption mono  
- 工具按钮：统一 ghost icon button  

### 3.8 移动端 ＜1024px

```
TOPBAR
[ 分镜 | 预览 | 属性 ]  segment 切换  ← 映射现 mobilePanel
STAGE or LIST or INSPECTOR
TIMELINE 可折叠为「时间线 ▾」
```

### 3.9 功能保全清单（精修台）

- 播放/暂停/seek/键盘快捷键  
- 分镜选择、多选批量重生成  
- TTS/图重生成、上传、版本切换  
- 时间线重排、hold、撤销重做  
- 生成 run 的暂停/继续/取消/重试  
- 导出对话框  
- BGM/字幕项目设置保存

## 5. 关键流（用户路径）线框级

### 路径 A：新手一条龙

```
开始创作 → 步骤1 生成文案 → 自动填分镜数 → 步骤2/3 轻量确认
→ 步骤4 勾选 →「生成并进入精修」→ 精修台看预览 → 导出
```

### 路径 B：回到作品

```
作品库 → 打开精修 → 改一镜 → 导出
```

### 路径 C：配置

```
设置 → 填 Key → 回开始创作（顶栏不再恐吓）
```
