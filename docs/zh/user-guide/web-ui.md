# Web 界面使用指南

## 剪辑工作台

在快捷创作中确认 1-100 个分镜后，默认创建项目并进入剪辑工作台；需要跳过精修时仍可直接生成成片。左栏用于场景与项目素材，中间预览当前确认画面，右栏编辑旁白、提示词和候选版本，底部时间线调整顺序与额外停留时间。

重新生成图片只添加候选，点击“使用此版本”后才会替换预览和导出引用。上传图片保存在当前项目内；修改旁白不会自动产生 TTS 任务，需显式点击重新生成配音。批量操作只支持提示词前缀和图片生成。

导出默认要求每个场景有当前图片和音频，并冻结当前版本快照。不完整导出需要二次确认。历史记录中的已完成或失败任务可通过“打开工作台”物化为项目，原历史记录保持不变。

## 界面布局

桌面端由导航、创作工作区和可折叠任务面板组成。窄屏下，导航和任务面板会变为抽屉，创作工作区保持完整宽度。顶部服务状态来自当前配置与后端检测结果；“未检测”不等于服务可用。

快捷创作按五个阶段组织：内容、分镜、声音与画面、核对并生成、进度与结果。编辑内容会自动保存为当前浏览器草稿，刷新页面后可恢复。

## 内容输入

### 生成模式

- **AI 生成内容**: 输入主题，AI 自动创作文案
- **手动分镜**: 为每个分镜分别编辑旁白和画面提示词
- **批量生成**: 一行一个主题，每个主题创建一个独立视频任务

### 固定文案分割方式

使用固定文案模式时，可选择文案的分割方式：

- **按段落分割**: 以空行为分隔符，每个段落作为一个分镜
- **按行分割**: 以换行符为分隔符，每行作为一个分镜
- **按句子分割**: 智能识别句子边界，每句话作为一个分镜

### 背景音乐

- 支持内置音乐
- 支持自定义音乐文件

## 语音设置

### TTS 工作流

- 选择 TTS 工作流
- 支持 Edge-TTS、Index-TTS 等

### 参考音频

- 上传参考音频进行声音克隆
- 支持 MP3/WAV/FLAC 等格式

---

## 视觉设置

### 图像/视频生成

- 选择媒体生成工作流（图像或视频）
- 调整提示词前缀控制风格

### 视频模板

- **模板预览画廊**: 可视化预览所有可用模板
- 支持竖屏 (1080x1920) / 横屏 (1920x1080) / 方形 (1080x1080)
- 模板类型：
  - `static_*.html`: 静态模板（无 AI 生成媒体）
  - `image_*.html`: 图像模板（需要 AI 生成图像）
  - `video_*.html`: 视频模板（需要 AI 生成视频）

## 生成视频

提交前必须核对视频数、分镜数、配音、工作流、画布、字幕、背景音乐和预计旁白时长。提交期间按钮会锁定，同一请求使用幂等键避免重复任务。

点击「生成视频」按钮后，系统会：

1. 生成视频文案
2. 为每个分镜生成配图/视频
3. 合成语音解说
4. 合成最终视频

生成完成后自动预览。

运行中的任务可在任务面板取消。取消、失败和完成是三个不同的终态，并会与历史记录保持一致。批量任务可以逐项取消或重试。

!!! note "预览资产"
    TTS 试听、“合成当前文案”和测试出图仅用于确认配置，不会直接复用到最终成片；正式生成会按最终核对参数重新生产。

## 项目级生成运行

工作台的“开始生成”会按时间线顺序扫描全部场景，跳过指纹和文件均有效的素材。缺失或过期场景先生成 TTS，再用真实音频时长回填时间线，随后生成图片。运行面板显示当前场景、阶段、总进度和失败统计，并提供暂停、取消和“仅重试失败项”。暂停和取消是协作式信号，不会强制终止正在进行的外部请求。

已有 current 图片的场景会把新图片保存为候选版本，不会自动替换预览或导出快照。当前生成场景会锁定，等待中的场景仍可编辑。queued、running、paused 运行会持久化，API 重启后可从未完成阶段恢复；浏览器运行期间每秒轮询一次，进入终态后停止。
